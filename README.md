# Canvas Openbot

Aplicativo desktop portátil para Windows x64: notas, tarefas, imagens, conexões, desenho, histórico e integração OpenBot configurável.

## Baixar o programa

[Baixar Canvas Openbot para Windows x64](https://github.com/Fxndoo/Canvas-/releases/download/v0.2.0/Canvas-Openbot-0.2.0-windows-x64.zip)

Extraia a pasta inteira e abra **Canvas Openbot.exe**, mantendo os demais arquivos juntos. Python e Electron estão incluídos.

[Releases e código-fonte completo](https://github.com/Fxndoo/Canvas-/releases/tag/v0.2.0)

O código-fonte completo está no anexo Canvas-Openbot-0.2.0-source.zip da release. Code → Download ZIP baixa os arquivos desta página, não o programa Windows.

## Dados e integração

Dados no perfil local: AppData/Roaming/Canvas Openbot. A integração com agentes vem desativada; configure no botão Integração. A API escuta em 127.0.0.1; OpenBot remoto exige conexão segura configurada pelo usuário. Nenhum dado pessoal ou credencial acompanha o programa.

## Versão de validação

Pacote montado e inspecionado em Linux; ainda não executado em Windows ou no notebook. Treze testes do backend passaram na VPS. Sem assinatura própria de código. Consulte instruções e limitações nos anexos da release.
