# Canvas Openbot

Aplicativo desktop portátil para Windows x64: notas, tarefas, imagens, conexões, desenho, histórico e integração OpenBot configurável.

## Baixar o programa

[Baixar Canvas Openbot — versão 0.2.0](https://github.com/Fxndoo/Canvas-/releases/tag/v0.2.0)

Na página acima, baixe as duas partes **.zip.001** e **.zip.002**, além de **Juntar-Canvas.cmd**, na mesma pasta. Execute Juntar-Canvas.cmd para reunir e conferir o ZIP. Extraia a pasta inteira e abra **Canvas Openbot.exe**, mantendo os demais arquivos juntos. Python e Electron estão incluídos.

O código-fonte completo está no anexo **Canvas-Openbot-0.2.0-source.zip** da release. Code → Download ZIP baixa os arquivos desta página, não o programa Windows.

## Dados e integração

Dados no perfil local: AppData/Roaming/Canvas Openbot. A integração com agentes vem desativada; configure no botão Integração. A API escuta em 127.0.0.1; OpenBot remoto exige conexão segura configurada pelo usuário. Nenhum dado pessoal ou credencial acompanha o programa.

## Versão de validação

Pacote montado e inspecionado em Linux; ainda não executado em Windows ou no notebook. Treze testes do backend passaram na VPS. Sem assinatura própria de código. Consulte LEIA-ME.txt na release.
